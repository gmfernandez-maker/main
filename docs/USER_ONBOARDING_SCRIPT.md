# PixelPioneers User Navigation Script

This script can be used for onboarding demos, tutorial voiceovers, or in-app walkthrough text.

## Audience
- First-time users
- Returning users who want to review grading and history

## Goal
Guide users from account access (Sign Up or Log In) to:
- Capturing or selecting jewelry images
- Running grading
- Viewing result details
- Estimating value
- Opening and understanding history

## Full Walkthrough Script

### 1. Welcome Screen
Narration:
"Welcome to JewelGrade. This app helps you analyze jewelry photos, estimate likely karat confidence, and keep a grading history for future review."

User action:
- Open the app.
- On the welcome/auth screen, choose either Sign Up or Log In.

### 2. Sign Up Flow (New Users)
Narration:
"If this is your first time, tap Sign Up and create your account so your grading history can be saved."

User action:
- Tap Sign Up.
- Enter required details (for example: name, email, password).
- Confirm and submit.
- Complete any verification step if shown.

Narration:
"Once registration is successful, continue to the main grading screen."

### 3. Log In Flow (Returning Users)
Narration:
"If you already have an account, tap Log In and enter your credentials to continue where you left off."

User action:
- Tap Log In.
- Enter email/username and password.
- Tap Continue.

Narration:
"You are now signed in and ready to grade an item."

### 4. Start a New Grading Session
Narration:
"To begin grading, capture a clear photo or upload an existing image of your jewelry item."

User action:
- Tap the capture/upload entry point.
- Choose camera or gallery.
- Ensure the jewelry is centered, in focus, and well-lit.
- Confirm the selected image.

Narration:
"A clear photo improves analysis quality and confidence scoring."

### 5. Run Analysis
Narration:
"Now run the analysis to generate your jewelry grading result."

User action:
- Tap Analyze, Grade, or the equivalent action button.
- Wait for processing to complete.

Narration:
"The app combines visual indicators and stamp evidence to estimate confidence and grade details."

### 6. Review the Grading Result
Narration:
"On the Jewelry Analysis Report, review the key outputs shown on screen."

User action:
- Check the overall confidence/score.
- Review material and karat clues.
- Read any short evidence notes or guidance.

Narration:
"Remember: this is a probabilistic estimate and should be validated by a professional jeweler for formal appraisal."

### 7. Add Stamp Closeup (Optional but Recommended)
Narration:
"For better confidence, add a closeup photo of the karat stamp when available."

User action:
- Tap Add Karat Stamp Closeup.
- Capture or select a focused stamp image.
- Let OCR process the stamp.

Narration:
"If stamp confidence is high enough, the result is updated and the total score can improve."

### 8. Estimate Value in Item Summary
Narration:
"You can estimate scrap and resale value using your item weight and current pricing assumptions."

User action:
- Enter item weight in grams.
- Tap Estimate Value.
- Read compact Item Summary values:
  - Scrap/Melt value
  - Resale value
- Tap the small circular info button to see how values are calculated.

Narration:
"Use the info button whenever you want the full formula and assumptions behind the estimate."

### 9. Save and Exit Result Screen
Narration:
"Your analysis is stored in history, allowing quick comparisons over time."

User action:
- Return from the result screen using Back or the app navigation.

### 10. Open History
Narration:
"To review previous analyses, open History from the main navigation."

User action:
- Tap History.
- Browse graded items.
- Open any entry to view details, confidence indicator, and saved value estimate when available.

Narration:
"History helps track your repeated scans and compare outcomes across different captures."

### 11. End of Tutorial
Narration:
"You are all set. Capture clearly, review confidence carefully, and use history to monitor your grading results."

## Short Version (30-Second Script)
"Open PixelPioneers and Sign Up or Log In. Start a new scan by taking or uploading a clear jewelry photo, then run analysis. Review the confidence-based result and, if available, add a closeup of the karat stamp to improve scoring. In Item Summary, enter weight to estimate scrap and resale values, then tap the info icon to view the formula and assumptions. Finally, open History to revisit all saved grading results and value estimates."

## Presenter Notes
- Keep wording simple and avoid promising exact appraisal accuracy.
- Emphasize that results are estimates.
- Encourage clear lighting, focus, and centered framing for best performance.
- Encourage users to use stamp closeups whenever possible.
